# Code Warrior ⚔️

[![Version](https://img.shields.io/badge/version-0.0.2-blue.svg)](https://github.com/syauqisuhaimi/codewarrior)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

> Fight bugs and level up as you code in VS Code!

Code Warrior is a gamified VS Code extension that transforms your coding experience into an RPG adventure. Battle enemies, level up, earn money, and purchase powerful weapons as you write code!

## ✨ Features

- **🎮 Gamified Coding Experience**: Every character you type deals damage to enemies
- **📊 Real-time Stats**: Track your progress with a status bar showing level, enemy HP, and money
- **🛒 In-Game Shop**: Purchase weapons and items to increase your attack power
- **🏆 Level System**: Level up as you defeat enemies and earn rewards
- **📈 Progress Tracking**: Visual sidebar showing your stats, current enemy, and available items
- **💰 Currency System**: Earn money by defeating enemies and spend it in the shop

### Usage

Once installed, Code Warrior will automatically activate when you start VS Code. Simply start coding and watch as:

1. **Every character you type** deals damage to the current enemy
2. **Defeat enemies** to earn money and level up
3. **Open the Code Warrior sidebar** from the activity bar to view your stats
4. **Purchase items** from the shop to increase your attack multiplier
5. **Track your progress** in the status bar at the bottom of VS Code

## 🎯 Commands

- `Code Reward: Show Stats` - Display your current stats in a popup
- `Code Reward: Reset Stats` - Reset your progress and start over

## 📊 Game Mechanics

### Combat System

- Each character typed = 1 base damage × attack multiplier
- Enemies have HP that scales with your level
- Defeating an enemy grants money and experience

### Shop System

The shop includes various weapons and items.

Each item has:

- Attack bonus (increases your damage multiplier)
- Price (required money to purchase)
- One-time purchase (permanent upgrade)
